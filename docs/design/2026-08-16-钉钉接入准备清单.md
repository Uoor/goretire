# 「校友安居」钉钉接入准备清单

> 目标：拿到免登（AppKey/AppSecret/CorpId）与机器人推送所需凭证，让代码里的
> `DingTalkClientImpl`（真实换号）与 `DingTalkPushClient`（真实发送）能联调闭环。
> 配套环境变量模板：`backend/.env.example`、`frontend/.env.example`

---

## 0. 前提与最快路径

- **前置**：一个钉钉组织（企业/团队）+ 一个企业内部应用。
- **最快联调组合**：AppKey + AppSecret + CorpId（免登）+ 群自定义机器人 Webhook（群推送）。
  不需要 Stream 长连接也能跑通"免登换 JWT + 新上架卡片推群"。

---

## 1. 钉钉组织（自建企业/团队）

| 项 | 操作 |
|----|------|
| 创建组织 | 钉钉 App → 我的 → 通讯录 → 创建/加入团队 → 按指引创建企业（可"免费试用"，后续认证） |
| 邀请校友入编 | 管理后台（oa.dingtalk.com）→ 通讯录 → 成员管理 → 邀请成员/批量导入 |
| 目的 | 离职校友不在阿里通讯录，必须自建组织承载"校友"身份 |

## 2. 企业内部应用（H5）

| 项 | 操作 |
|----|------|
| 入口 | 电脑浏览器打开 **open.dingtalk.com** → 登录（管理员/开发者账号） |
| 创建 | 开发者后台 → 应用开发 → 企业内部应用 → **创建应用** |
| 填写 | 应用名称"校友安居"、Logo、应用首页地址（H5 URL，可先填占位，上线前改） |
| 工作台入口 | 应用详情 → 版本管理与发布 → 配置"工作台"入口（可选，先联调可不配） |

## 3. AppKey / AppSecret（最核心，免登 + 机器人 token 都靠它）

| 项 | 位置 |
|----|------|
| 查看 | **应用详情页 → 凭证与基础信息** → AppKey / AppSecret |
| 安全 | AppSecret 只显示一次或需验证；**只填到后端 `.env`，绝不进前端/代码库** |
| 填写 | `backend/.env` → `DING_APP_KEY` / `DING_APP_SECRET` |

## 4. CorpId（组织 ID，前端免登 requestAuthCode 需要）

| 项 | 位置 |
|----|------|
| 查看方式 1 | open.dingtalk.com 开发者后台首页（右上角组织信息）或应用详情页，形如 `dingxxxxxxxxxxxx` |
| 查看方式 2 | 钉钉管理后台 oa.dingtalk.com → 首页 → 企业信息 → CorpId |
| 填写 | 后端 `backend/.env` → `DING_CORP_ID`；前端 `frontend/.env` → `VITE_DING_CORP_ID`（钉钉容器内免登用） |

## 5. H5 免登与 JSAPI 域名配置

| 项 | 操作 |
|----|------|
| 服务器域名 | 应用详情 → 开发配置 → **服务器域名**：填写后端 HTTPS 域名（JSAPI 校验用） |
| 部署要求 | 钉钉容器内 H5 要求 **HTTPS**；本地联调用 dev 桩可跳过 |
| 免登流程 | 前端 `requestAuthCode(corpId)` → 拿 code → POST /api/auth → 后端用 AppKey/Secret 换 userid |

## 6. 机器人（推送）

### 方式 A：群自定义机器人 Webhook（最快，够 MVP）
| 项 | 操作 |
|----|------|
| 创建 | 钉钉群 → 群设置 → 智能群助手 → 添加机器人 → **自定义**（webhook） |
| 获取 | 创建后得到 Webhook URL，形如 `https://oapi.dingtalk.com/robot/send?access_token=xxx` |
| 填写 | `backend/.env` → `ROBOT_WEBHOOK`，`ROBOT_ENABLED=true` |
| 限制 | 只能发该群，无法发私聊/工作通知（群卡片足够 MVP） |

### 方式 B：企业内部机器人（能力全：可发工作通知/私聊）
| 项 | 操作 |
|----|------|
| 创建 | 应用详情 → **机器人** → 创建机器人 → 选企业内部机器人 |
| 回调 | **Stream 模式**：无需公网回调 URL（长连接，代码骨架已按此设计）；HTTP 模式需公网 URL |
| 权限 | 需申请"机器人发送消息"权限（见 §7） |

## 7. 权限点（应用详情 → 权限管理）

| 权限 | 用途 |
|------|------|
| 通讯录个人信息读权限 | 免登换 userid、查组织成员确认校友身份 |
| 工作通知权限 | 私聊触达（订阅/求租匹配提醒） |
| 机器人发送消息权限 | 群消息/交互卡片 |

> 企业内部应用权限审批快（几乎即时）；按需最小化申请。

## 8. 部署与回调（上线阶段）

| 项 | 要求 |
|----|------|
| 服务器 | 轻量 ECS 2C2G 即可；跑后端 jar + Nginx |
| 域名 | 一个 HTTPS 域名（Nginx + 证书），配置到"服务器域名/应用首页地址" |
| 前端静态 | 可同机 Nginx 托管 build 产物，或 OSS/CDN |

---

## 填好后如何验证

```bash
# 1) 后端带凭证启动
cd backend && set -a && source .env && set +a
java -jar app/target/aliren-app-0.1.0-SNAPSHOT-exec.jar --server.port=8081
# 2) 日志确认：启动时 DingTalkClientImpl / DingTalkPushClient 被装配（不再是 stub）
# 3) 钉钉内打开 H5 → 免登成功返回 JWT；发布审核通过 → 群里收到新上架卡片
```

**联调顺序建议**：先 AppKey/AppSecret/CorpId 打通免登 → 再 Webhook 打通群推送 → 最后按需上企业内部机器人/工作通知。
