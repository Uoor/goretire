# 招聘模块（aliren-recruit）实现方案

> 状态：待确认（确认后再写代码）
> 一句话：在 aliren 后端新增一个**独立 Maven 模块**，实现"钉钉群里 @ 招聘机器人 → 实时查多维表 → 回复到群里"的双向交互。

---

## 1. 目标与边界

- **结构**：独立 Maven 模块 `recruit`（`com.aliren.recruit`），与 `core`/`houserent` 平级。
- **功能范围**：**只做 @ 回复交互**。不建本地表、不做招聘信息 CRUD、不做管理后台。
- **取数方式**：回复时**每次实时查钉钉多维表（Aitable）**，不存本地副本。
- **接收方式**：Stream 模式（WebSocket 长连接，订阅 `RobotCallback`），无需公网回调域名。

## 2. 模块依赖与目录

### 2.1 依赖方向（单向）
```
core ← recruit ← app ← test
```
- `recruit` 仅依赖 `core`（复用 common：BusinessException / 配置等）。
- `app` 追加依赖 `aliren-recruit`。
- `test` 经 `app` 传递拿到 recruit 做测试。

### 2.2 目录结构（对齐 house 自包含包风格）
```
backend/recruit/
└── src/main/java/com/aliren/recruit/
    ├── robot/         # @ 回复接收
    │   ├── RecruitReplyClient.java      # 接口：start/stop/handleMention
    │   ├── StreamRecruitReplyClient.java# Stream 实现（@ConditionalOnProperty 启用）
    │   ├── RecruitReplyClientStub.java  # 缺省桩（日志模拟）
    │   └── GroupMentionMessage.java     # 入站 @ 消息模型
    ├── aitable/       # 多维表实时查询
    │   ├── AitableClient.java            # 接口：query(String keyword) -> List<RecruitRecord>
    │   ├── AitableDingTalkClient.java    # 真实实现（调多维表开放 API）
    │   ├── AitableClientStub.java        # 缺省桩
    │   └── RecruitRecord.java            # 招聘记录模型（字段对齐多维表列）
    └── config/        # RecruitReplyAutoConfig：按开关装配（Stub / Stream + Aitable 真实实现）
```

## 3. 核心流程

```
@ 进群（企业内部应用机器人已加入）
   ↓  Stream 长连接订阅 RobotCallback 主题，收到 @ 事件
解析 GroupMentionMessage（openConversationId / senderStaffId / text / msgId）
   ↓  AitableClient.query(text)   ← 实时查多维表
拼回复（匹配到的招聘记录 → 文本/markdown；无结果回引导话术）
   ↓  POST /v1.0/im/robot/groupMessages/send（robotCode + openConversationId + msgKey=sampleText）
回复到群里
```

- 去重：按 `msgId` 短窗口去重。
- 群过滤：`conversationType==2` 才处理。
- 容错：查询异常/无结果 → 回固定引导话术；Stream 断线自动重连。

```yaml

  recruit:
    enabled: ${RECRUIT_ENABLED:false}        # 总开关，默认关（fail-closed）
    robot:                                    # 招聘机器人（用于收 @ + 回复）
      app-key: ${RECRUIT_DING_APP_KEY:}
      app-secret: ${RECRUIT_DING_APP_SECRET:} # 敏感，仅 env 注入
      robot-code: ${RECRUIT_ROBOT_CODE:ding4xccwzeyg83iij2u}
      agent-id: ${RECRUIT_AGENT_ID:4631726481}
    aitable:                                  # 多维表访问凭证 + 表定位
      app-key: ${RECRUIT_AITABLE_APP_KEY:}
      app-secret: ${RECRUIT_AITABLE_APP_SECRET:}  # 敏感
      base-id: ${RECRUIT_AITABLE_BASE_ID:}        # 多维表 Base ID（待确认）
      table-id: ${RECRUIT_AITABLE_TABLE_ID:}      # 数据表 ID（待确认）
    reply:
      mode: ${RECRUIT_REPLY_MODE:stream}
      no-result-tip: ${RECRUIT_NO_RESULT_TIP:暂时没有匹配到，换个说法试试或联系管理员}
```

> 敏感项（两个 secret）由部署者以 `.env` 环境变量注入，**不落 git**。
