设计意图

  • 移动端：单列卡片，360px 宽，信任清单常驻按钮上方（A 方案）。
  • PC 端（≥768px）：左右分栏占满 1200px 内容区，信息不重复——左侧 = 说服（品牌 + 信任清单，信任项从紧凑卡变成列表项，信息更舒展）；右侧 = 行动（独立登录卡 ~420px，只有标题 + 钉钉蓝按钮）。信任清单只在左侧出现一次。
  • 社群绑定前置：左侧展示「仅限社群成员使用」徽章 + 点名「阿里人·一起提前退休」。
  • 企业边界：橙色高亮「仅关联社群企业，阿里/蚂蚁企业信息技术上无法获取」——"做不到"比"承诺不碰"更有说服力。
  • 按钮：钉钉官方蓝 #0089FF（与 base.css .dingtalk-login-btn 一致），强化"钉钉官方授权"感知。

组织校验链路

  • 扫码 → 后端按应用所属企业校验成员身份；非组织内成员 → 302 回 /#/login?error=not_in_org → 弹窗 → 跳 /join（已实现，见 AuthController.oauthCallback）。
  • 钉钉容器内 JSAPI 免登不受此页影响，仅浏览器扫码场景展示。
