## 1. 技术选型（已拍板）

| 项 | 选型 | 说明 |
|----|------|------|
| 框架 | Vue 3 + Vite | 钉钉 H5 生态主流 |
| UI 库 | Vant 4 | 移动端组件全（表单/卡片/弹层/日历） |
| 路由 | Vue Router（**hash 模式**） | 钉钉容器内刷新不 404 |
| 状态 | Pinia | 用户态/订阅态 |
| 请求 | Axios + 拦截器 | 统一带 token；401 自动重新免登并重放 |
| 适配 | postcss-px-to-viewport（vw） | 一套代码适配全机型 |
| 图标 | Phosphor Icons（web 包） | 与原型一致（`ph` 类） |
| 钉钉 | dd.config + JSAPI 封装（utils/dd.js） | 免登/扫码/分享 |

## 3. 工程结构（frontend/，壳 + 业务模块）

```
frontend/
├── index.html                  # 入口（viewport / 字体）
├── package.json / vite.config.js / postcss.config.js
└── src/
    ├── main.js                 # createApp + pinia + router + vant
    ├── App.vue                 # 根组件（router-view）
    ├── styles/                 # 设计令牌 tokens.css + 全局 base.css（跨模块）
    ├── api/                    # 跨模块基础接口（auth）
    ├── components/             # 跨模块通用组件
    ├── store/                  # 全局状态（user）
    ├── router/                 # 路由壳（hash + 懒加载业务模块页面 + 守卫）
    ├── utils/                  # request / dd / format（基础设施）
    └── modules/                # 业务模块目录（目前仅 houserent，未来按域扩展）
        └── houserent/          # 租房模块（全部租房页面/组件/接口）
            ├── views/          # Home/Detail/Demand/Publish/Subscribe/Me
            │   └── admin/      # 管理后台（/admin 路由，运营角色校验）
            ├── components/     # 房源卡片等模块内组件
            └── api.js          # 租房接口（houses/demands/subscriptions/match/admin）
```

**模块边界约定**（与后端 houserent 对齐）：
- 壳层（styles/api/components/store/router/utils）= 跨模块基础设施，任何模块共用；
- 业务代码按域进 `src/modules/<module>/`（页面 views/ + 组件 + 模块内 api），
  目前只有 `houserent`（租房），未来新业务域新增目录即可，壳不动。

## 4. 页面与路由

底部导航 5 Tab（与原型一致）：首页(home) / 求租(demand) / 发布(publish 中间凸起) / 订阅(subscribe) / 我的(me)。

| 路由 | 页面 | 后端接口 |
|------|------|---------|
| `/` | 首页·房源广场 | GET /api/houses + POST /api/match/search |
| `/house/:id` | 房源详情 | GET /api/houses/{id} + POST /api/houses/{id}/reports |
| `/demand` | 求租墙 | GET/POST /api/demands |
| `/publish` | 发布房源 | POST /api/houses |
| `/subscribe` | 订阅中心 | GET/POST/PUT/DELETE /api/subscriptions |
| `/me` | 我的（发布/需求/订阅管理） | GET /api/houses/mine 等 |
| `/admin` | 管理后台（审核/举报/看板） | GET/POST /api/admin/* |

## 5. 免登流程

```
① dd.ready → requestAuthCode() 取 code → POST /api/auth → 后端换 userid 签发 JWT
   → 前端存 token（localStorage）→ 后续请求带 Authorization
② Axios 拦截器自动附 token → 401 清除 token → 重新免登 → 重放请求（用户无感）
③ 路由守卫：未登录（无 token）→ 触发免登
```

## 6. 设计规范补充（来自原型）

- **房源卡片 6 要素**：价格/户型、押付方式、标签、已核实标、通勤、联系按钮（卡片即决策单元，不堆信息）
- **筛选 chips**：区域/价格/户型/标签/可养宠/通勤/新上架
- **中间凸起发布按钮**：tabbar 视觉重心
- **页面底**：`--bg`（#F5F5F4）；卡片 `--card` 白底 + `--border` 分隔
- 图标统一 Phosphor（regular），尺寸 1.4rem 级
