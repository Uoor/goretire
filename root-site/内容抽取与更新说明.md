# 内容抽取与更新说明

## 官网角色

官网现阶段是“社区前厅”，不是知识库目录，也不是独立内容平台。

它需要同时提供四种理由：

- 值得相信：能看到社区起源、公开规则和信息边界。
- 值得回来：能快速知道最近群里与外部在发生什么。
- 值得使用：有轻量工具和直接可读的结论。
- 值得连接：知道怎样进群、找人、分享资源或谈合作。

## 页面由哪些数据驱动

门户页面内容集中在 `src/data/portalContent.ts`：改数据即可改页面，不需要动组件。

| 页面区域 | 数据字段 | 说明 |
| --- | --- | --- |
| 顶部导航 | `navigation[]` | 锚点数组，锚点必须与页面上的版块 `id` 一一对应（当前启用 4 项，`#community-invites` 那项被注释掉） |
| 品牌字标 | `brand` | `name` / `caption` / `symbol`，顶部与页脚共用 |
| 每日 bot 推送 | `topics[]` | 每项含 `label` / `accent` / `intro` / `image` / `imageAlt`，切换主题时展示对应预览图 |
| 知识库 | `knowledge.shared[]`、`knowledge.ali` | 阿里专区在共享条目之后追加 `knowledge.ali` |
| 大厂社群 | `companyNetworks[]`、`companyNetworksShowAll` | 仅在首页渲染；URL 带 `?debug=1` 时预览全量 |
| 子群服务 | `communityGroups[]` | 三组卡片（每日交流 / 金融工具 / 工作生活），每条链接含 `label` / `url`，可选 `qrImage` + `qrAlt` |
| 首屏关注卡与页脚 | `footer.qrCodes`、`footer.tagline`、`footer.filing` | 公众号二维码、slogan、备案号 |

图片统一放 `assets/`，数据里写相对路径（如 `assets/bots-gold.jpg`），由 `src/utils/assetUrl.ts` 拼接部署前缀。

**约束**：任何带 `qrImage` 的链接都必须同时给出 `qrAlt`，带预览图的主题必须给出 `imageAlt`；`tests/verify-site.mjs` 会对页面文案、版块锚点、资源字段与样式令牌做静态校验，端到端检查在 `tests/browser-qa.mjs`。

### 已下线的旧结构

改版前的静态站点遗留已在 2026-10-03 门户并入本仓库时删除，门户不再读取它们：`assets/content-data.js`（`window.COMMUNITY_CONTENT`）、`assets/site.js`、`assets/ali.css`、`src/data/webpack.config.cjs`、`src/App.tsx`。挂在旧首页的「群聊摘要 / 每日信号」板块在那之前就已随改版下线，因此本文档不再描述它们的数据字段。

## 内容更新流程

### 每日 bot 推送

输入：现有机器人、公开知识库、可信外部信息源。

处理：

1. 每条必须保留来源、时间和有效期。
2. 把事实与群友观点分开。
3. 涉及市场的信息只做事实和学习交流，不做收益承诺或个股建议。
4. 人工确认后更新 `topics[]` 的 `intro` 与预览图。

建议频率：按机器人事件实时入池，每天人工精选后更新。

### 长期内容

优先把现有知识库抽成“一个结论 + 一个工具 + 一个资料入口”：

- 房产框架 → 租/买/卖三问工具。
- 房产指标字典 → 城市、板块、小区比较卡。
- 离职 SOP → 分阶段清单。
- AI 内容 → 岗位工作流和权限边界。
- 投资复盘 → 事件日历、风险问题和群友复盘。
- 身份/港卡资料 → 场景、成本、维护三项比较。
- 资源福利 → 来源、适用人群、有效期、关系说明四字段。

### 群聊内容

原始群聊不直接上首页。若将来要恢复群聊类板块，先按下面的匿名化规则整理，再新增数据字段与对应组件：只抽取主题、共识、分歧和可继续讨论的问题；删除姓名、头像、联系方式、公司内部信息与可识别细节；合并相似话题；人工确认后再上页面，并展示更新时间而不是未经核验的群消息量。

## 不能自动公开的内容

- 原始群聊全文、成员姓名、头像、手机号和联系方式。
- 公司内部材料、未公开业务信息和私人经历细节。
- 未核验的合作权益、房源、岗位和活动。
- 金融产品销售、收益承诺或以社区名义给出的投资建议。

## 当前仍需补齐

- 小助理二维码或独立联系页。
- 视频号与企业微信入口（公众号二维码已上线）。
- 各机器人可公开的准确名称、来源和推送节奏。
- 合作资源的提交表单与审核负责人。
- 群聊内容的授权范围与人工审核人（恢复相关板块前必须先落实）。
