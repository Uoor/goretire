# 上线配置清单

## 页面结构（当前实现）

- 单 HTML 入口的 SPA：首页 `/` 与阿里专区 `/ali` 由客户端路由切换，其余路径落到 404 页。
- 顶部轮播承载首屏：桌面端「关注我们 → Hero」，移动端「Hero → 关注我们」并把关注卡逐张拆成独立 slide。
- 版块顺序：大厂社群（仅首页）→ 内容观点 → 子群服务 → 资源互助。
- 页面数据集中在 `src/data/portalContent.ts`，全站样式在 `assets/site.scss`。
- **单独发布本目录不会上线**：门户与租房 H5（仓库根 `frontend/`）由 `scripts/build-web.mjs` 汇总成同一产物树，用 `./scripts/deploy-web-remote.sh` 一条命令发布。

## 已完成

- 双路由，以及吸顶的顶部锚点导航（滚动高亮当前版块）。
- 每日 bot 推送的 10 个主题与知识库入口（钉钉文档，共 2 条共享 + 阿里专区 1 条）。
- 大厂社群卡片：首页默认只展示阿里卡片，URL 带 `?debug=1` 可预览全量轮播。
- 子群服务的钉钉入群链接与二维码：首页为静态标签，`/ali` 悬停查看二维码、点击打开入群链接。
- 金融内容风险提示，以及页脚工信部备案号。
- 桌面端与移动端响应式样式（断点 700px）。
